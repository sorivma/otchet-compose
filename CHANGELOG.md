## [Unreleased]

## [0.3.2] — 2026-06-05

### Исправлено

- CLI заранее проверяет возможность записи DOCX/manifest и возвращает машинно-читаемую ошибку `output_write_failed`, если выходной файл нельзя создать.

## [0.3.1] — 2026-06-04

### Изменено

- GitHub Actions обновлены до Node.js 24-совместимых `checkout@v6` и `setup-python@v6`.

## [0.3.0] — 2026-06-04

### Добавлено

- Команда `validate` для проверки конфигурации без генерации DOCX.
- Стабильный JSON-режим `--json` для команд `gen` и `validate`.
- Команды `inspect` и `schema` для машинного discovery.
- Версионируемая JSON Schema конфигурации, включённая в пакет и используемая при валидации.
- Флаги `--dry-run`, `--force` и `--output-root` для безопасной генерации.
- Опциональный SHA-256 manifest входов и выходов через `--manifest`.
- Неинтерактивный `init --non-interactive` для агентного создания стартовых конфигураций.

### Изменено

- Ошибки CLI выводятся в `stderr`; ошибки входных данных возвращают exit code `2`.
- Предупреждения генерации в JSON-режиме возвращаются в массиве `warnings`.
- DOCX записывается атомарно; существующий файл не перезаписывается без `--force`.
- Pytest всегда импортирует пакет из текущего `src`, а не установленную копию.

### Исправлено

- LLM-reference теперь перечисляет реальные встроенные шаблоны `rut` и `mock`.

## [0.2.0] — 2026-05-31

### Добавлено

- Поддержка свойства `keep_together` в описании стилей (`styles.json` / `styles.py`).

### Изменено

- **Рисунки:** изображение (или placeholder) и подпись «Рисунок N – …» вставляются в одну
  двухстрочную таблицу без видимых рамок; на обе строки установлен `w:cantSplit`, чтобы блок
  не разрывался между страницами.
- **Подписи таблиц:** стиль `GOST Table Caption` получил `keep_with_next`; при рендере подпись
  дополнительно помечается `keep_with_next`, чтобы не отрываться от таблицы.
- **Подписи рисунков:** стиль `GOST Caption` получил `keep_together`.
- **Оглавление:** поле TOC создаётся с флагом `dirty=True` и пустым placeholder-текстом вместо
  напоминания об ручном обновлении; в `settings.xml` добавляется `w:updateFields`, чтобы Microsoft
  Word пересчитывал оглавление при открытии документа.

### Исправлено

- Placeholder рисунка без файла: рамка только вокруг ячейки с изображением, подпись — отдельной
  строкой под ним (раньше placeholder и подпись могли оказаться на разных страницах).

### Тесты

- `tests/blocks/test_figure.py` — проверки подписи обновлены под новую табличную разметку.
